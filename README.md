# CURA FEMINAE

Website pentru proiectul medical **CURA FEMINAE** din Constanța — centru pentru sănătatea femeii, în dezvoltare.

## Status

- Next.js
- build validat în GitHub Actions
- conținutul public marchează explicit serviciile, echipa și spațiul drept planificate / conceptuale acolo unde este cazul
- Marc Anton Cruceanu este prezentat ca unic medic obstetrician-ginecolog planificat al centrului
- structura viitoarei echipe este prezentată ca dependentă de finanțare, autorizare și recrutare
